# FlowCAD

Browser-based 3D CAD modeler. Everything runs client-side: no server, no account, no upload.

## Status

Milestone 1 (core viewer + CSG) is working:

- Three.js viewport, Z-up, millimetre grid, orbit/pan/zoom
- Watertight primitives generated by the Manifold kernel: cube, cylinder, sphere
- Boolean union / subtract / intersect, run in a Web Worker so the UI never blocks
- Click to select, shift-click to add a second object (first = target, second = tool)
- Move / rotate / scale gizmo with snapping (1 mm, 15 degrees, 0.1)
- Undo / redo, 200 levels
- Binary STL export of the selection, or of everything when nothing is selected

## Shortcuts

| Key | Action |
| --- | --- |
| W / E / R | Move / rotate / scale |
| Delete | Delete selection |
| Ctrl+Z, Ctrl+Y | Undo, redo |
| Esc | Clear selection |

## Architecture

| Path | Role |
| --- | --- |
| `src/viewport.ts` | Scene, camera, renderer, orbit controls |
| `src/document.ts` | Scene objects, selection, gizmo, undo history |
| `src/csg/` | Manifold WASM worker, typed request protocol, promise client |
| `src/io/stl.ts` | Binary STL encoder |
| `src/toolbar.ts` | Toolbar and keyboard bindings |

Every object keeps its indexed watertight mesh (`SolidData`) alongside the display mesh. Booleans and
export read the watertight data; the display mesh only adds creased normals for shading.
